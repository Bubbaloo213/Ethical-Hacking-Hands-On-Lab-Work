## Task 1: ARP Cache Poisoning

<details>
  <summary> Why is ARP / ARP Cache? </summary>
              * ARP (Address Resolution Protocol): A networking protocol that allows a computer to discover the MAC address associated with an IP address on the same local network. This helps the computer deliver data to the correct device.

* ARP Cache: A temporary address book stored in each computer's memory that keeps track of IP addresses and their corresponding MAC addresses. This prevents the computer from having to send a new ARP request every time it communicates with the same device.

* In simple terms: ARP finds the MAC address, and the ARP cache remembers it.
</details>

## Task 1.C – ARP Cache Poisoning Using a Gratuitous ARP Request

<details>
  <summary> What is a Gratuitous ARP Request? </summary>
             **Gratuitous ARP Request** is when a computer announces its own IP-to-MAC mapping to everyone on the local network, without waiting for anyone to ask.

For example, User 1 might announce:
***"Hello everyone! My IP address is 10.9.0.6, and my MAC address is 02:42:0a:09:00:06."***

This can help other computers update outdated information in their ARP caches.

</details>


<details>
  <summary> How does the Attacker exploit this? </summary>
            The Attacker sends a forged announcement:
***"Hello everyone! My IP address is 10.9.0.6, and my MAC address is 02:42:4b:3d:79:e5."***

The Attacker is pretending to be User 1, hoping the Victim will associate User 1's IP address with the Attacker's MAC address.

</details>
