# Lab 3.1 - ARP Cache Poisoning

**Objective**
The objective of this exercise is to learn how an attacker attempts to trick the victim machine into associating User 1's IP address (10.9.0.6) with the attacker's MAC address. 

## Assumptions
- In this lab, we have three machines. Run ***docker ps*** to view them.
       
      - 1 attacker machine: seed-attacker (IP: 10.9.0.1 | MAC: 02:42:4b:3d:79:e5) --- seed@ab9dcd563e24
      - 1 victim machine: IP Address - (IP: 10.9.0.5 | MAC: 	02:42:0a:09:00:05) --- seed@427c2bcaa4b
      - 1 user machine: IP address - (IP: 10.9.0.6 | MAC: 	02:42:0a:09:00:06) --- root@db8e5927398c
      - 1 user machine: IP address - 10.9.0.7 --- root fbe0d770a020

### Create your **settings.txt** file
5. Create a **settings.txt** file containing the IP and MAC addresses of the three computers. Run:


  ```javascript
  nano settings.txt
  ```

6. Paste the following:

  ```javascript
  IP_A=10.9.0.5
MAC_A=02:42:0a:09:00:05
IP_B=10.9.0.6
MAC_B=02:42:0a:09:00:06
MAC_M=02:42:4b:3d:79:e5
payload=
  ```

* Leave payload= empty for now. We'll fill it in when we reach the later tasks.

7. Save the file:

    - Press Ctrl + O to save.
    - Press Enter to confirm.
    - Press Ctrl + X to exit Nano.
