## Task 2: Create your automated traceroute Python script

2. **Traceroute** works by sending packets with increasing TTL values. Since your assignment asks for a fully automated traceroute, we'll use a Python loop to do this automatically.
3. In the Attacker terminal, run:

  ```javascript
  nano /home/seed/traceroute.py
  ```

5. Copy this Python code

  ```javascript
#!/usr/bin/env python3

from scapy.all import *

ttl = 1

while True:
    a = IP(dst="8.8.8.8", ttl=ttl)
    b = ICMP()
    p = a/b

    pkt = sr1(p, timeout=2, verbose=0)

    if pkt is None:
        print("TTL: %d, No response" % ttl)

    elif pkt.haslayer(ICMP) and pkt[ICMP].type == 0:
        print("Complete ", pkt[IP].src)
        break

    else:
        print("TTL: %d, Source: %s" % (ttl, pkt[IP].src))

    ttl += 1

    if ttl > 30:
        print("Maximum number of hops reached.")
        break
  ```
