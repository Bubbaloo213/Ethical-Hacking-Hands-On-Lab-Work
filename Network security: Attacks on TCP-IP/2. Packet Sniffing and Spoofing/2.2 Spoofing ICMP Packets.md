# Lab 2.2 - Spoofing ICMP Packets

**Objective**
The objective of this lab is to demonstrate how IP spoofing works by using Scapy to create and send an ICMP packet with a fake source IP address (8.8.8.8). In this exercise, I configured an ICMP Echo Request with a spoofed source IP address of 8.8.8.8 and a destination IP address of 10.9.0.5. I then used Wireshark to capture and verify that the packet was successfully transmitted with the modified source address. This exercise helped me understand how attackers can manipulate packet headers to disguise the origin of network traffic.

## Task 1: Scapy to create and send an ICMP packet with a fake source IP address.

### Create then ICMP spoofing Python script

1. Open attacker terminal (SEED Lab). Run:

  ```javascript
  nano /home/seed/spoof_icmp.py
  ```

2. Paste the following Python code:


  ```javascript
#!/usr/bin/env python3

from scapy.all import *

ip = IP(src="8.8.8.8", dst="10.9.0.5")
icmp = ICMP()

packet = ip/icmp

packet.show()
send(packet)
  ```

**Important:** Although the attacker VM's actual IP address is 10.9.0.1, we'll make the packet appear to originate from 10.9.0.6. This is what makes it IP spoofing.

3. Once you've entered the code:
   * Press Ctrl + O to save.
   * Press Enter to confirm.
   * Press Ctrl + X to exit Nano.

#### Execute the ICMP spoofing python script
4. Spoof ICMP packets by running:

  ```javascript
  sudo python3 /home/seed/spoof_icmp.py
  ```
