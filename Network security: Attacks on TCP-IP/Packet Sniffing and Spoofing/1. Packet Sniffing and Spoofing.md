## Task 1: Packet Sniffing and Spoofing Lab

**Objective**
The objective of this exercise is to use Scapy to capture and analyze ICMP packets transmitted between the SEED Lab VM and a Docker container.

**Procedure**
Identified the network interface br-c84de5716c52, associated with IP address 10.9.0.1, using the ip -br addr command.

1. Created a Python script named sniffer.py to capture ICMP packets using Scapy.
2. Executed the script with root privileges using sudo python3 /home/seed/sniffer.py.
3. Opened a second terminal and generated ICMP traffic by executing ping -c 4 10.9.0.5.
4. Observed the ICMP Echo Request and Echo Reply packets captured by Scapy.

**Conclusion**
This exercise demonstrated how Scapy can be used to sniff and inspect network packets. By applying an ICMP filter, the sniffer captured ping-related traffic and displayed packet information, including source and destination IP addresses and ICMP message types.

### Create packet-sniffing Python script
3. Create a Python program that captures network packets. Run:

  ```javascript
  nano /home/seed/sniffer.py
  ```

4. Copy and paste the following code into Nano:

  ```javascript
  #!/usr/bin/env python3

from scapy.all import *

def print_pkt(pkt):
    pkt.show()

pkt = sniff(iface='br-c84de5716c52', filter='icmp', prn=print_pkt)
  ```

### Generating network traffic and capturing ICMP packets.

<details>
  <summary> What is a ICMP packet? </summary>
              ICMP (Internet Control Message Protocol) is a network protocol that computers and networking devices use to communicate information about network connectivity and errors. ICMP is a way for one computer to ask another: ***“Hello, are you reachable?”*** And the other computer can respond: ***“Yes, I'm here!”***
</details>
