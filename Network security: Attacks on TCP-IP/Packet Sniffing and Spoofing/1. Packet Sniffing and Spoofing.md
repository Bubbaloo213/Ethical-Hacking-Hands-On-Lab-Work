## Task 1: Packet Sniffing and Spoofing Lab

### Identify your network interface

1. Before capturing network packets using Scapy, we need to identify which network interface the SEED Lab uses. Run:

  ```javascript
  ip -br addr
  ```

2. The SEED Lab instructions indicate that we should look for the interface associated with IP address 10.9.0.1.

### Create packet-sniffing Python script
3. Create a Python program that captures network packets. Run:

  ```javascript
  nano /home/seed/sniffer.py
  ```

4. Copy and paste the following code into Nano:

  ```javascript
  #!/usr/bin/env python3

from scapy.all import *

def print_pkt(pkt):
    pkt.show()

pkt = sniff(iface='br-c84de5716c52', filter='icmp', prn=print_pkt)
  ```

5. Once you've entered the code:
   * Press Ctrl + O to save.
   * Press Enter to confirm.
   * Press Ctrl + X to exit Nano.

6. You've successfully saved your first packet-sniffing Python script. 


### Run Packet Sniffer

7. Execute **sniffer.py** to start listening for network packets. Run:


  ```javascript
  sudo python3 /home/seed/sniffer.py
  ```
